# 😊 Real-Time Emotion Detection using Python

## 📌 Overview

This project is a **Real-Time Emotion Detection System** developed using **Python, OpenCV, TensorFlow, and DeepFace**. It captures live video from a webcam, detects faces, and predicts the user's facial emotion in real time.

The system can identify emotions such as **Happy, Sad, Angry, Fear, Surprise, Disgust,** and **Neutral**, making it useful for AI and computer vision applications.

---

## 🚀 Features

* 🎥 Real-time webcam emotion detection
* 😀 Detects multiple facial emotions
* 👤 Automatic face detection
* ⚡ Fast and accurate emotion prediction
* 🖥️ Displays detected emotion on the live video

---

## 📦 Installation

Clone this repository:

```bash
git clone https://github.com/your-username/Emotion-Detection.git
```

Go to the project folder:

```bash
cd Emotion-Detection
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python emotion_detection.py
```

The webcam will open automatically and display the detected emotion in real time.
